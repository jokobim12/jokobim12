## 👨‍💻 Tentang Saya

<img align="right" width="180" src="https://github.com/jokobim12.png" alt="Foto Profil"/>

Halo! Saya **Joko Bimantaro**, mahasiswa Program Studi D3 Teknologi Informasi di Politeknik Negeri Tanah Laut. 

Saya memiliki ketertarikan mendalam pada dunia rekayasa perangkat lunak, pengembangan web full-stack, pengelolaan basis data, serta integrasi sistem dan otomatisasi digital. Perjalanan saya di dunia teknologi dimulai sejak usia 16 tahun, dan sejak saat itu saya terus mengeksplorasi teknologi modern untuk membangun solusi yang berdampak.

Di luar aktivitas ngoding, saya aktif mengeksplorasi produksi konten digital kreatif serta gemar mengikuti perkembangan sepak bola internasional.

> **Prinsip Hidup:** *"Terus belajar, berani mencoba, dan ciptakan solusi teknologi yang bermanfaat bagi sesama."*
